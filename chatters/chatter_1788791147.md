上节课我们已经讲过了 API Key 和 URL 是什么（至于如何获得 Key，最简单的是去 DeepSeek 官网充一点，虽然只能用 DeepSeek；而其他的渠道，例如 GPT、Grok、Gemini 等可以咨询站主，后面也会介绍）。

> **回顾**：API Key 和 URL——URL 是餐厅地址、Key 是钥匙兼银行卡、模型名是点哪个厨师。

这节课我们就来介绍一下该怎么用它。但在此之前，我们必须明白一个概念——大模型和客户端。

## 大模型和客户端

以 DeepSeek 举例，你手机下载了一个 DeepSeek 客户端，具有让他①联网搜索、②你问一句答一句的能力。实际上这些能力来源不仅仅是 DeepSeek 的大模型，而且有很大一部分是客户端的能力。

大模型是脑子。目前 DeepSeek 的模型更新到了 deepseek-v4-pro/flash，当你把问题发给算力中心时，他作为大脑可以进行思考——用户问了什么？结果是什么？我该怎么回答？这就是大模型的能力。

但是，大模型没办法去网上查信息，也没办法直接告诉你自己思考的结果。也就是说，你虽然有 DeepSeek 模型，但他是被关在铁房子里的聋哑人，虽然能思考，但是没有办法读写，也没办法与外界交流。

于是客户端就起到这样一个作用：你把问题发给客户端，客户端把问题送给算力中心的大模型，大模型思考以后把结果传递回客户端，客户端再把结果用文字的方式告诉你。（如果你需要让他联网搜索，实际上是客户端调用了其他的工具收集信息）

在这个过程中，大模型担任“大脑”的职责，只负责规划和思考就行了；然后客户端担任一个“眼睛和嘴巴”甚至部分“手脚”的功能，传达信息甚至调用工具。于是大模型和客户端在一起就形成了一个完整的 AI 工具。

那我们的 Key 里是什么？是连接算力中心的钥匙。通过这个钥匙你可以连接到算力中心，但是依然没办法把信息发送给算力中心，也没办法从算力中心获取信息。所以很明显的，我们需要一个客户端！

这边针对电脑端和安卓手机，我分别介绍两个客户端以供调用。
