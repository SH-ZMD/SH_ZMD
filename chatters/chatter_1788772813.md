## 为什么不用豆包？

先问一个问题：你充过豆包会员吗？应该是没有。

那有免费的客户端豆包，为什么还有人买会员？——因为模型能力和功能不同。很多人觉得，会员能用更多的功能，比如能做更多 PPT，能生成更多图片和更多视频，但这只看到了部分，更重要的其实是模型能力。

举个例子，豆包现在的版本更新到了 2.1，但你没有充钱，他只给你落后的 1.5 版本，而且还是降低了算力的 1.5 版本。这就是你为什么觉得豆包笨——记不住东西（实际上叫“上下文短”）、瞎编史料（出现幻觉）、算个数学题都能出错（模型能力太差），还一味迎合你。

## 问题来了！我们怎么才能用到更聪明、更严谨、更不会瞎编东西的模型？

答案：花钱买。（实际没花多少钱，后面再讲怎么花更少的钱）

- 算力不够？出钱给公司买算力就好。
- 模型落后？出钱买最新的模型就好。

## 两种用上最新最好模型的方法

### 1. 充会员

这是最广泛、最简单的第一种方式：购买各大公司的 Coding Plan（也就是会员），然后他给你最好的模型、最多的算力。诸如月之暗面公司（代表模型 Kimi）的 199 套餐、OpenAI 公司（代表模型 GPT）的 20 美元 Plus 订阅。

![](/image/pasted-1788771747356-b4709d.webp)

**优点**：简单方便，而且能直接用，适合小白。

**缺点**：一个月一百多元的会员价格有些贵了，而且作为一个学生，大概率也用不完给的这么多算力。

### 2. 使用 API Key

这里我们必须明确一个概念：简单来说，就是这些公司先搭建了算力中心，模型的计算都在这些算力中心进行，然后他们给这个算力中心一个接口，也就是 API。

于是你想使用这些模型，就需要连接这些算力中心：把自己的问题发送给算力中心，算力中心计算完毕，返回给你。恭喜你，你完成了一次典型的 API 调用——把问题发给算力中心，计算完毕后他再告诉你他的结果。

那问题来了：我该怎么连接算力中心？于是就有了两个概念：**URL** 和 **Key**。

举个例子：我想要调用深度求索公司的 DeepSeek 模型，而且要的不是那种网页版的阉割模型，要最聪明的模型。于是我得先想办法连接到 DeepSeek 公司，这就是 URL。DeepSeek 的 URL 是：

<https://www.deepseek.com/>

对的，你能看到，这就是 DeepSeek 的网址，我们通过这个网址可以连接到 DeepSeek 的服务器。

然后呢？我们调用 DeepSeek 模型，人家肯定不可能随便给陌生人用他们的模型，肯定得让人家知道我们是谁。于是我们可以去申请一个 Key，这个 Key 相当于是一个账号，通过这个账号可以登录到人家的算力中心，然后人家从我们的账号里扣钱，让我们用他们的模型。

![](/image/pasted-1788772205797-f90116.webp)

于是我们就有了 API Key 和 URL：连接上了服务器，而且有了服务器账号，就可以直接调用算力中心了！

至于如何使用，下期讲。

> **PS**：聪明的小伙伴可能可以看出来，实际上第一种方法（充会员）和 API 是一样的，都是通过账号和 URL 连接到算力中心，然后付费使用。不过充会员的话更简单，调用起来也更方便，而且同样量的算力，充会员相当于买了打折扣的 API Key——比如你花 100 块买了 1 亿 token 的 API Key，那你把这 100 元充会员可能能买 2 亿。

## 那么我们为什么不充会员，而是买 API Key？

一方面，不是每个公司都有自己的会员，例如 DeepSeek 他们现在没有自己的会员，只能调用 API Key（其他公司部署的不算，后面再说）。

另一方面，你充了会员就要在一个月内用完，不然浪费了；而且你充了会员就只能在这里用，想换个客户端用也不行，不够灵活。
