很多同学总问我这个问题——我会了，那该怎么用 Codex 呢？我们先明白 Codex 是什么。

国外一家最厉害的 AI 公司叫 OpenAI，他们研发了一系列超级厉害的大模型——GPT 系列（最近火起来说解决了 ns 数学问题、辅助了黎曼猜想什么的大模型），然后他们专门给 GPT 做的 Harness 叫做 Codex（不过现在整合成了 ChatGPT）。

**GPT 的特点**：智力高、严谨、便宜（大概吧）。

**GPT 的缺点**：慢、降智，还有最近不断地报错！（算力不够了）

## 但我们要先明白一些事情

### 1. Codex 是很好，但不通用——不要给他接入别的大模型

Codex 太臃肿，又专门为 GPT 开发。如果你给他接入别的模型（包括 DeepSeek），他会因为不熟悉环境变得很笨很笨！

所以，用 Codex 就用 GPT，不然就没有 Codex 存在的价值了（暴论）。

### 2. Codex 很厉害，但不适合所有的任务

比如这两句话：

> “给我找一下这个文件里的这个人考了多少分”
>
> “帮我找一下这个模组的前置文件”

这种不注重思考、注重工具调用和执行的，还是直接使用别的模型就行了（例如 gemini-3.8-flash）。用 Codex 会非常、非常、非常慢！

### 3. 那什么时候使用 Codex 呢？

在你有比较重要的项目，而且需要比较严谨的规划的时候。

## 到这里我们切入正题——怎么使用 Codex？

### 1. 下载 Codex

先搜索 Microsoft Store（这里正常用你的网就行了！不然可能打不开！），然后搜索 ChatGPT 打开就好！

![](/image/pasted-1788966080320-c074d6.webp)

![](/image/pasted-1788966262440-119673.webp)

到这里你就有了 ChatGPT 了，打开他会让你登录。

![](/image/pasted-1788966372066-e0d4f0.webp)

如果你有账号可以直接登录，然后花 140 充值一个 Plus 会员账号，这个需要很多东西：

- 你要每个月 20 美元；
- 你要有境外支付方式；
- 你要有 ___（跳过，大家应该知道是什么）。

但我们都小白了就不看这个了，直接采用第二种方法——依旧 API 这一块。你直接点击 API 登录，然后随便输入几个数字进去（当然没法用，我们随便输入以后就是能进去 Codex 的界面，但是没办法用）。

![](/image/pasted-1788966521712-f2de7b.webp)

### 2. 连接外部 API Key

首先下载个 CC Switch：

> **链接**：[CC Switch 官方网站 - AI 编程工具统一管理平台](https://www.ccswitch.io/zh/)

这个有什么用？——把我们的 API Key 和 Codex 连接起来。

![](/image/pasted-1788966641932-b5c29f.webp)

然后按下面的步骤操作：

1. 先进入设置，把本地路由关了。

   ![](/image/pasted-1788966671161-96785e.webp)

   ![](/image/pasted-1788966691937-e078ff.webp)

2. 点击这个 ChatGPT 图标（注意第一个箭头这里指的图标，这个表明我们要对 Codex 进行修改了），接着点击右上角的加号。

   ![](/image/pasted-1788966737486-fed009.webp)

3. 自定义配置——名字随便、官方链接不填、API Key 和 URL 你应该知道是什么了。

   ![](/image/pasted-1788966799293-ce58f9.webp)

4. 直接点击右下角的添加就可以了（其他配置以后有需要再讲）。

5. 这个时候最上面应该有个 ChatGPT Official 之类的什么，删掉就好，保留你刚刚加入的那个 Key 就好，然后点击启用即可——这个时候 CC Switch 就把你的 Codex 配置成你的 Key 和 URL 了！

   ![](/image/pasted-1788966873441-f8a57b.webp)

6. 这时候重启 ChatGPT 就可以使用了！

   ![](/image/pasted-1788967165835-b8e4c0.webp)
